# Athletes-Performance-Dashboard

## Project Overview (Visão Geral do Projeto)
Este projeto foi desenvolvido para ajudar treinadores e equipas técnicas a analisar o rendimento físico e a forma dos atletas. O objetivo principal é transformar dados brutos de treinos em decisões rápidas sobre quem está apto para competir.

---

## ETL & Data Cleaning (Limpeza de Dados no Power Query)
Os dados originais estavam desorganizados. Utilizei o **Power Query** para estruturar tudo.
* **Principais ações:**
  * Remoção de linhas em branco e duplicadas.
  * Correção do tipo de dados (Texto, Números Inteiros e Datas).

---

## Data Modeling & DAX (Modelação e Fórmulas)
Para o relatório funcionar bem, criei as relações entre tabelas e escrevi fórmulas em **DAX** para calcular as métricas importantes.

---

## Competências Demonstradas
* Microsoft Power BI Desktop
* Power Query (Processo de ETL)
* Escrita de fórmulas em DAX
